# 阅画 (Yuehua)

> 当前版本：**v0.0.2**（2026-11-04）· 程序集版本与 git tag 一致

快速打开、多格式支持、可标注、可另存为特定大小的图片查看器。

## 功能特性

-   M0：NativeAOT + Avalonia + Magick.NET 技术验证骨架
-   M1：快速打开 / 文件夹导航 / 缩略图条
-   M2：进阶标注（图形 + 文字 + 画笔 + 马赛克遮挡 + 图层 + 线性历史记录）
-   M3：另存为特定大小（像素尺寸 / 文件体积；裁剪导出待做）
-   M4：现代紧凑 UI + 楷体「画」字圆角图标（四角透明）+ 黄金分割窗口居中 + 关闭时旋转 / 翻转保存提示 + NativeAOT 单目录发布
-   M5：工具条玻璃化（半透明浮在图上，图片从底下透出来）+ 顶栏默认贴顶固定不遮挡画面 + 可拖到桌面快捷方式 / 命令行打开（支持多张，单实例转交给已开窗口）
-   M6：ICO 查看（`.ico` 已纳入「打开图片」过滤与扫描；多分辨率帧挑面积最大一帧渲染，告别 16×16 缩略）+ 顶栏并入标题栏、底部栏并入状态栏（均固定常驻，不再浮动 / 自动隐藏）+ ICO 导出「背景」选项（透明 / 白 / 黑 / 自定义色，默认**透明**，根治旧版「ICO 全黑」）+ 打开失败主动报错（不再静默跳文件）+ 默认窗口尺寸收窄（0.56 比例）
-   M7：修复 ICO 导出「空白图标」（合成丢失源图，所有帧全透明）+ 每帧强制 32 位 RGBA PNG + 专注模式下标题栏常驻（可退出、可关闭）+ 重置视图改为明确图标按钮 + 另存为按钮移到「打开文件夹」右侧；后续补：ICO「最大尺寸」下拉可调、标题栏按钮垂直居中、滚轮缩放百分比实时刷新、同名覆盖缓存自动失效、状态栏格式显示为真实文件类型

## 系统要求

- Windows 10 / 11 x64（起步平台）
- .NET 10 SDK
- Visual Studio 2022 Build Tools（勾选“使用 C++ 的桌面开发”，NativeAOT 链接所需）

## 构建命令

```bat
dotnet restore
dotnet publish src/Yuehua -c Release -r win-x64 --self-contained
```

AOT 原生产物位于 `src/Yuehua/bin/Release/net10.0/win-x64/publish/`（约 22 MB 的 `Yuehua.exe` + 4 个原生依赖 DLL：`Magick.Native-Q8-x64.dll` / `libSkiaSharp.dll` / `av_libglesv2.dll` / `libHarfBuzzSharp.dll`，共约 63 MB）。

> **分享给别人**：由于 Magick / Skia 原生库在 NativeAOT 单文件打包时会出现版本错乱（运行报 libSkiaSharp 版本不匹配），**单文件 exe 不可靠**。推荐做法：把整个 `publish/` 目录打包成 zip（仓库已生成 `yuehua-win-x64.zip`，约 25 MB），对方解压后双击 `Yuehua.exe` 即可，**无需安装 .NET**。**切勿只发一个 exe**——缺少旁侧的 4 个 DLL 会无法启动。

若链接阶段报 `Platform linker not found` 或 `LNK1181`（注册表探测被拦截的环境），改用一键脚本：

```bat
powershell -ExecutionPolicy Bypass -File tools\build-aot.ps1
```

快速验证 Magick.NET 在 AOT 下可运行：

```bat
dotnet publish src/Yuehua.M0Check -c Release -r win-x64 --self-contained
.\src\Yuehua.M0Check\bin\Release\net10.0\win-x64\publish\Yuehua.M0Check.exe
```

## 使用说明

| 操作 | 入口 |
| --- | --- |
| 打开图片 / 文件夹 | 顶栏左端图标，或直接把文件、文件夹拖进窗口 |
| 拖到桌面快捷方式打开 | 把一张或多张图片（也可整个文件夹）拖到 `Yuehua.exe` 的桌面快捷方式上松开；已有窗口会直接显示这批图并把窗口叫到前台，不会再开第二个窗口（想强制多开：命令行加 `--new-instance`） |
| 上一张 / 下一张 | ← / →，或顶栏箭头、底部缩略图条 |
| 缩放 / 适应窗口 / 1:1 | + / -、滚轮；Ctrl+R 或底部状态栏的四角框图标（「重置视图 / 适应窗口」）复位；旁边显示当前缩放百分比读数，右侧 `1:1` 为原始像素 |
| 旋转 / 翻转 | 底部状态栏的旋转 / 翻转图标 |
| 进入标注模式 | Ctrl+E，或顶栏铅笔开关（默认关闭，看图优先） |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y；侧栏「标注」页还有一条**历史记录**，点任意一步可直接跳过去（最多 60 步） |
| 切换当前图层 | 侧栏「标注」页点图层行；被选中的层会高亮（左侧强调竖条 + 加粗），新标注都落到该层 |
| 另存为指定大小 | Ctrl+S，或顶栏**「打开文件夹」右侧**的导出图标 →「另存为」对话框；侧栏「导出」页也有入口 |
| 打开设置 | Ctrl+,，或顶栏齿轮图标 |
| 专注模式（隐藏工具条 / 状态栏 / 面板 / 浮动卡片） | F11；标题栏**始终保留**，右上角有专门的四角框「退出专注」按钮，窗口最小化 / 最大化 / 关闭按钮也一直可用 |
| 深浅色切换 | Ctrl+D |
| 退出标注 / 退出专注 | Esc，或 F11，或标题栏右上角「退出专注模式」按钮 |
| 窗口大小 | 默认取主屏工作区的 0.56 比例并居中（较旧版 0.618 更紧凑）；打开即「纯看图」——侧边面板与底部缩略图条默认隐藏，需要时再点**底部状态栏**的对应开关唤出 |
| 关闭保存提示 | 当图片被旋转 / 翻转且尚未保存时，点关闭会弹「是否保存」：保存（打开「另存为」导出旋转 / 翻转后的图）/ 不保存 / 取消 |
| 大文件夹性能 | 缩略图条默认隐藏；仅当唤出缩略图条时才在后台逐张生成，前台先显示文件名占位，生成中显示「生成缩略图 n/总」进度，切换文件夹自动取消上一次未完成的生成 |
| 底部状态栏（缩放 / 旋转 / 翻转 + 面板 / 缩略图开关 + 位置） | 固定常驻在窗口底部，与状态文字合并，不再单独浮动或隐藏；缩放 / 适应 / 1:1 / 旋转 / 翻转及面板、缩略图开关都在这里，打开即见，无需额外唤出 |
| 侧边栏关闭 | 侧边栏右上角「×」按钮，关闭后由底部状态栏的「侧边面板」开关重新唤出 |
| 打开失败提示 | 主动打开（拖入 / 双击 / 打开对话框）某文件却无法解码时，弹「无法打开文件」对话框并停留在原文件，**不再静默跳到别的同目录图片**；导航翻页（←/→）失败仅更新状态栏、不弹窗 |

「另存为」对话框支持两种模式：

-   指定像素尺寸：直接给宽高，或点 100% / 75% / 50% / 25% / 1920 宽 快捷按钮，可锁定宽高比，实时显示缩放百分比。
-   指定文件体积：给目标 KB，有损格式（JPEG / WebP）二分搜索质量，无损格式（PNG / BMP / TIFF）二分搜索缩放尺寸。ICO 走专属分支，尺寸由「最大尺寸」决定，不受导出模式影响。

导出格式下拉含 `ico`：把当前图（含标注与旋转 / 翻转）生成一组标准分辨率正方形图标，写入单个 `.ico`。ICO 格式目录项宽高仅 1 字节（0 = 256），故任一边不得超 256；每帧以 PNG 嵌入（绕开 Magick 小帧调色板透明怪象）。选 `ico` 时对话框会自动隐藏「方式 / 宽高 / 质量 / 插值」这些对本格式无效的控件，改显示 ICO 专属的两项：

**① 最大尺寸**（下拉：16 / 24 / 32 / 48 / 64 / 72 / 96 / 128 / 256，默认 256）。ICO 本质是「一包多尺寸」的容器，选最大边长后会自动生成所有不超过它的标准帧，并在下方列出实际帧集合：

| 选最大尺寸 | 生成帧数 | 帧集合 |
| --- | --- | --- |
| 16 | 1 | 16 |
| 48 | 4 | 16 / 24 / 32 / 48 |
| 128 | 8 | 16 … 128 |
| 256（默认） | 9 | 16 / 24 / 32 / 48 / 64 / 72 / 96 / 128 / 256 |

> 若你看到图标「只有 16×16」，多半是**查看器默认展示 ICO 的第一帧**（ICONDIR 第一项就是 16×16），文件里其实包含上面全部尺寸；资源管理器小图标视图、部分浏览器都有这个行为。需要确认时用能列出各帧的 ICO 工具，或看阅画状态栏（显示的是最大帧尺寸）。

**② 背景**（透明 / 白 / 黑 / 自定义色）：

-   **透明（默认）**：等比居中、四周留透明边，原图透明度得以保留，适合本身带透明通道的图（如 PNG 源）。这从根本上修复了旧版「ICO 全黑」——旧版用 `Alpha(Off)` 把透明像素抹成黑色，现已改为贴合到透明画布、绝不丢 alpha。
-   **白 / 黑**：铺满正方形并压平到白 / 黑底色，不保留透明，适合拿图片直接当不透明图标（最不容易在深色背景下显黑）。
-   **自定义色**：同上，但底色取你填的十六进制色（`#RRGGBB`；填错则回退白）。

不论哪种背景，各分辨率帧都以 **32 位 RGBA（8 位 / 通道）PNG** 嵌入 ICO，透明信息得以保留。这里有两处容易踩的坑，均已修掉：

-   **合成必须显式 `CompositeOperator.Over`**：Magick.NET 的 `Composite(image, Gravity)` 重载默认并非 Over，直接用会把源图整个丢掉，只留下空画布 —— 表现就是导出的 ICO 每一帧都 100% 全透明（在查看器里显示为空白 / 全黑 / 打不开），且不同源图会产出大小完全一样的空文件。
-   **PNG 必须强制 RGBA**：少色图会被 Magick 按「最小体积」量化成 1 位灰度 / 黑白调色板 PNG，与目录项声明的 32bpp 不符，部分查看器因此解析异常。写出前设置 `png:color-type=6` + `Depth=8` 即可固定为真彩 + alpha。

修复后已用 Magick.NET（与阅画同一解码路径）读回验证：9 帧、最大帧 256×256、有彩色内容、透明底帧 alpha 覆盖 0..255、白底帧 alpha 全 255。

**查看 ICO**：阅画自身支持直接打开 `.ico` 查看——「打开图片」对话框与文件夹扫描均已纳入 `.ico`，打开时会挑面积最大的分辨率帧渲染（避免被当成 16×16 缩略图）。状态栏左侧显示「宽 × 高 · 格式」，对多帧 ICO 会显示形如 `256 × 256  ·  ICO（共 9 帧，当前显示最大帧）`，含义是「当前显示的是这一包图标里最大的那帧」，不是文件只有一个尺寸。注意：**Windows「照片」(Photos) 应用不支持 `.ico` 格式**，用它打开导出的图标会报「很抱歉，照片无法打开此文件，因为当前不支持该格式，或文件已损坏」——这**不是文件损坏**，换个支持 ICO 的查看器（如本程序）即可正常打开。

**同名覆盖自动刷新**：图像缓存现在带文件签名（修改时间 + 大小）。把新导出的 ICO 覆盖到已打开的同名文件时，主界面会自动重新解码，不会再出现「主界面还是旧图、缩略图条却是新图」的错位。缩放百分比读数也改为即时计算，滚轮缩放时数字实时跟着变。

导出默认尺寸为当前图片的原始像素；手动改过宽高后不再随翻页重置（点 100% 可恢复跟随）。
导出会保留当前的旋转 / 翻转（烘焙进导出图）；缩放仍以原始像素为准，不会放大模糊。勾选「把标注烙进导出图」时标注会按原图比例烘焙进去。

## 工具条浮动样式

设置（Ctrl+,）里可逐条切换工具条的呈现方式：

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 标注工具箱浮动 | 开 | 浮于画面之上，圆角 + 阴影 + 半透明玻璃底，可用条顶手柄拖动位置；关闭则贴左缘固定并让出画面空间；仅标注模式出现 |
| 缩略图条浮动 | 关 | 关闭时贴底固定并占据画面下方空间；开启后浮在画面底部，宽度收窄 |
| 显示行为 | 空闲自动淡出 | 两档：**常驻悬浮** / **空闲自动淡出**。默认「空闲自动淡出」：看图时浮动卡片（标注工具箱 / 缩略图条）淡出、画面完整，鼠标一动即恢复；顶栏已固定并入标题栏，不参与隐藏 |
| 淡出延时 | 2 秒 | 仅「空闲自动淡出」模式下生效，范围 0.5–10 秒 |
| 复位工具条位置 | 按钮 | 浮动位置恢复默认（工具箱左中、缩略图贴底） |

半透明是**玻璃底**而不只是整体降透明度：浮动卡片的底色用主题里的玻璃画刷（浅色 `#C9FFFFFF` / 深色 `#C71D1D21`，约八成不透明），窗口顶部标题栏同样半透明（`#C4F7F7F9` / `#C218181B`），且图片会一直画到标题栏底下——所以图片边缘不会被一条实心色带切断。图标与文字始终不降透明度，保证看清。

固定模式不是「浮动关掉就没了」：工具条会贴回边缘并让出画面空间，图片不会被遮挡。
设置保存在 `%LOCALAPPDATA%\Yuehua\settings.json`，即时生效；专注模式（F11）只隐藏顶部工具条、底部状态栏、侧边面板与浮动卡片，**标题栏始终保留**，因此随时可以退出专注、最小化、最大化或关闭窗口。
旧版设置里的「空闲自动淡出」开关（AutoFade）会自动迁移成新的「显示行为」（false→常驻、true→空闲淡出），不会丢配置。
